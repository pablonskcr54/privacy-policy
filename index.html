Политика конфиденциальности

Discord-бот «ЭктоТян» · Дата вступления в силу: 3 ноября 2026 года

1. Какие данные мы собираем

Бот собирает минимальный объём информации, необходимый для работы функций экономики:

  • Числовой ID пользователя Discord — для привязки баланса к аккаунту;
  • Баланс монет и время последнего получения бонуса;
  • ID сервера (гильдии) — для разделения данных между серверами (при необходимости).

Бот не собирает: содержимое сообщений, личные данные (имя, email, телефон), IP-адреса или историю переписки.

2. Как мы храним данные

Данные хранятся локально в файле economy.json на компьютере владельца сервера, где запущен бот. Данные не передаются и не продаются третьим лицам.

3. Цель обработки

Данные используются исключительно для функционирования игровой экономики (балансы, ежедневные бонусы, передача монет, топ-10).

4. Хранение и удаление

Данные хранятся до тех пор, пока бот не будет остановлен или пока владелец бота не удалит файл economy.json. Для удаления своих данных обратитесь к владельцу сервера.

5. Третьи лица

Бот взаимодействует только с сервисами Discord (Discord API). Мы не делимся данными с рекламными или аналитическими сервисами.

6. Безопасность

Доступ к файлу данных ограничен владельцем устройства, на котором работает бот. Рекомендуем не передавать токен бота третьим лицам.

7. Контакты

По вопросам конфиденциальности обращайтесь к владельцу бота на сервере Discord.

Privacy Policy

Discord Bot "ЭктоТян" / "EktoTyan" · Effective date: 3 November 2026

1. Data We Collect

The bot collects only the minimum information needed for the economy features:

  • Discord user numeric ID — to link balances to accounts;
  • Coin balance and last bonus claim time;
  • Server (guild) ID — to separate data across servers when needed.

The bot does not collect message content, personal data (name, email, phone), IP addresses or chat history.

2. How We Store Data

Data is stored locally in the economy.json file on the computer of the server owner running the bot. No data is shared or sold to third parties.

3. Purpose of Processing

Data is used solely to run the in-bot economy (balances, daily bonuses, coin transfers, top 10).

4. Retention and Deletion

Data is kept until the bot is stopped or the owner deletes the economy.json file. To have your data removed, contact the server owner.

5. Third Parties

The bot interacts only with Discord services (Discord API). No data is shared with advertising or analytics services.

6. Security

Access to the data file is limited to the owner of the device running the bot. We recommend not sharing the bot token.

7. Contact

For privacy questions, contact the bot owner on the Discord server.
